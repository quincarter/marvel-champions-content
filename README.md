# Marvel Champions: Digital Edition, media bundles

Release assets only: the card art, music and art of [marvel-champions-digital-game](https://github.com/quincarter/marvel-champions-digital-game), as zip bundles, one release per bundle version. The game repo's `assets/manifest.json` names the release each bundle comes from, and `pnpm assets:fetch` downloads and verifies them. Releases are never deleted, so every commit of the game can still fetch the media it was built with.

Marvel Champions, its card text, artwork and characters are the property of Fantasy Flight Games and Marvel. This is a fan-made, non-commercial project.
